# Semana 6 — Aplicação funcional

**Objetivo:** consolidar a integração completa entre engenharia de dados, RAG auditável, consulta de dados vivos, sistema multiagentes e capacidades multimodais em uma aplicação funcional ponta a ponta.

**Foco no roadmap:** Integração completa · **Estado:** Planejado.

## 1. Escopo previsto

- Integrar todas as frentes validadas nas semanas anteriores em interface utilizável pelo usuário final, preservando proveniência, citações verificáveis, tratamento de ambiguidades e avisos de limite de cobertura.
- Garantir reprodutibilidade de execução, configuração de ambiente e suíte de testes ponta a ponta.
