## 2. Convenções desta pasta

- Cada pasta `semana-XX/` reúne o índice do entregável da respectiva semana, com links relativos para especificações (`docs/specs/`), relatórios (`docs/reports/`), scripts (`scripts/`), conjuntos de avaliação e resultados (`evals/`).
- Os arquivos originais em `docs/specs/` e `docs/reports/` permanecem em seus caminhos canônicos para preservar referências em código, scripts de publicação e testes automatizados.
- Nenhum documento declara concluída uma revisão humana, publicação ou etapa sem o respectivo artefato registrado no repositório.
